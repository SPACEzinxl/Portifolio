# Samuel Fernando | Desenvolvedor Júnior - Portfólio Profissional

Bem-vindo ao repositório do meu portfólio profissional! Este projeto foi desenvolvido para apresentar minhas habilidades, projetos práticos, certificados e trajetória acadêmica na área de desenvolvimento de software.

## 🚀 Sobre o Projeto

O portfólio é uma aplicação web estática e responsiva, focada em uma interface moderna e interativa (UI/UX). O objetivo principal é demonstrar de forma clara e visualmente agradável minhas competências como desenvolvedor júnior.

### 🌟 Principais Funcionalidades

- **Design Responsivo**: Adaptável a dispositivos móveis, tablets e desktops.
- **Dark/Light Mode**: Alternador de tema dinâmico que salva a preferência do usuário no `localStorage`.
- **Animações e Efeitos**: Efeito "máquina de escrever" (typewriter) dinâmico, animações de scroll e micro-interações em CSS/JS.
- **Filtros Dinâmicos**: Filtros por categoria nas seções de "Habilidades", "Projetos" e "Certificados".
- **Modais Interativos**: Visualização detalhada de projetos com vídeos e galerias de imagens.
- **Busca de Certificados**: Barra de pesquisa interativa para buscar certificados por palavras-chave.
- **Currículo para Impressão**: Uma página dedicada (`curriculo.html`) otimizada para ser salva ou impressa em formato PDF.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:

- **HTML5**: Estruturação semântica, acessibilidade e SEO.
- **CSS3**: Estilização, Flexbox, CSS Grid, variáveis nativas (Custom Properties) e animações.
- **JavaScript (Vanilla)**: Manipulação da DOM (ES6+), lógica de filtros, gerenciamento de estados visuais (modais e temas) e animações dinâmicas.
- **Google Fonts**: Tipografias *Plus Jakarta Sans* e *JetBrains Mono*.

## 📂 Estrutura do Projeto

- `index.html` - A página principal do portfólio.
- `curriculo.html` - Versão limpa do currículo pronta para impressão.
- `style.css` - Todos os estilos da aplicação e design system.
- `script.js` - Funcionalidades interativas (tema, navegação, modais, filtros e etc).
- `assets/` - Imagens, ícones e mídias de perfil.
- `Certificados/` - Arquivos PDF referentes aos cursos e qualificações.
- `projeto pokedex/` e `petshop3/` - Arquivos de mídia para exibição no portfólio de projetos.
